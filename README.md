# Ambi

a web app for discovering and ranking the best study spots (cafes, libraries, etc)


## Setup

mac terminal or etc
'''bash
npm install
npm run dev
'''

## Stack

react + vite + router v6 + css

## Pages

login - university email authentication
dashboard - browse and filter study spots
map view - explore spots on an interactive map
the ranker - head 2 head spot comparison
my study stack - your personal ranked list
settings - account preferences
