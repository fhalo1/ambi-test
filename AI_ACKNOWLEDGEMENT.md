AI Usage acknowledgement

For this project I used Claude for help when it came to CSS styling. I described the visual design I wanted using my Assignment 3 CSS and figma low fidelity mockups to have a clean minimal sidebar layout. I also reviewed and modified the output to match my design intentions, alongside having ease of accessibility when it came to color classes, respective spacing, and other contrasts issues I found in local testing. For map component, I had originally planned to use an external API, but due to feasibility and being a solo group, I asked Claude to help assist the component of MapView.jsx and used a coordinate based pin for where the latitude and longitude values were stored in the database, and converted to percentage positions on a somewhat styled div. I used Claude to implement the math for converting real Orange County, CA coordinates to CSS left/top percentages within the map bounding box, and then structure the popup component to appear as professional as possible when the pin was clicked. 

For the CSS styling, App.css lines are defined :root CSS variables like –accent, so the changing of these global color tokens changes the entire app consistently. -sidebar uses display: flex; flex-direction: column to stack the logo, nav links, and footer vertically with margin-top: auto on the footer to push it to the top. .spt-card uses position: relative so the .spot-score badge can use position: absolute; top: 12px; right: 12px regardless of the card content. The responsive block @media (max-width: 768px) switches the layout from side-by-side to stacked by changing .app-layout to flex-direction: column and .sidebar to flex-direction: row. For MapView.jsx the toPercent() function converts real coordinates to CSS percentages using a fixed bounding box for Orange County (lat 33.55–33.85, lng -118.05 to -117.75). And the formula ((spot.lng - (-118.05)) / 0.30) * 100 calculates how far across a 0.30 degree range the spot sits, which is expressed as a percentage of the map div width. transform: translate(-50%, -100%) on .map-pin centers the pin horizontally and then is able to anchor its bottom point to the coordinate. The popup uses position: absolute; bottom: 20px; right: 20px so it can appear in the corner of the map container regardless of which pin was clicked, And finally e.stopPropagation() on the pin's onClick prevents the click from going up to the map div's onClick, so there would be no closing of the popup.
